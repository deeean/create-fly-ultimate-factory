# Create: Ultimate Factory Fly

**[Create Fly](https://www.curseforge.com/minecraft/mc-mods/create-fly)**(ZurrTum의 Create Fabric 포크)용 커스텀 레시피 애드온 모드입니다.  
원본 [Create: Ultimate Factory](https://www.curseforge.com/minecraft/mc-mods/create-ultimate-factory)를 Create Fly용으로 포팅한 모드입니다. Compacting, Mixing, Haunting, Splashing, Crushing 머신에 33종의 레시피를 추가합니다.

## 요구사항

| 의존성 | 버전 |
|--------|------|
| Minecraft | 1.21.11 |
| Fabric Loader | >= 0.19.2 |
| Fabric API | >= 0.141.3 (리소스 로딩에 필요) |
| [Create Fly](https://www.curseforge.com/minecraft/mc-mods/create-fly) | >= 6.0.8 |

> **참고:** 이 모드가 Fabric API를 직접 사용하지 않더라도, 애드온 모드의 커스텀 레시피를 로드하는 리소스 로더를 제공하므로 Fabric API가 반드시 설치되어 있어야 합니다.

## 레시피 (총 33종)

### Compacting (9종) — 기계식 프레스 + Basin

| 입력 | 출력 | 조건 |
|------|------|------|
| 조약돌 + 용암 (1/3 양동이) | 응회암 | - |
| 돌 + 용암 (1/3 양동이) | 심층암 | - |
| 자갈 + 뼛가루 | 방해석 | - |
| 아연 조각 x4 + 자갈 + 물 (1/3 양동이) | 아쥬린 | - |
| 철 조각 x4 + 자갈 + 용암 (1/3 양동이) | 크림사이트 | - |
| 금 조각 x4 + 자갈 + 용암 (1/3 양동이) | 오크럼 | - |
| 구리 조각 x4 + 자갈 + 용암 (1/3 양동이) | 베리디움 | - |
| 블레이즈 가루 x4 | 블레이즈 막대 | - |
| 석탄 블록 x2 + 용암 (1 양동이) | 다이아몬드 | 블레이즈 버너 가열 필수 |

### Mixing (3종) — 기계식 믹서기 + Basin

| 입력 | 출력 |
|------|------|
| 네더랙 + 부싯돌 + 용암 (1/3 양동이) | 레드스톤 가루 x4 |
| 방해석 + 물 (1/3 양동이) | 점적석 블록 |
| 석탄 + 블레이즈 가루 | 화약 x3 |

### Haunting (6종) — 바람개비 + 영혼 불

| 입력 | 출력 |
|------|------|
| 현무암 | 네더랙 |
| 흑요석 | 우는 흑요석 |
| 목탄 | 석탄 |
| 양귀비 | 위더 장미 |
| 거미 눈 | 발효된 거미 눈 |
| 사과 | 후렴과 |

### Splashing (3종) — 바람개비 + 물

| 입력 | 출력 |
|------|------|
| 꽁꽁 언 얼음 | 푸른 얼음 |
| 마그마 크림 | 슬라임볼 |
| 염색된 테라코타 (16색 전체) | 테라코타 |
